# Support

Use [GitHub Discussions](https://github.com/AndrewUlloa/side-glance/discussions) for setup questions and usage help after discussions are enabled. Use the issue templates for reproducible bugs and feature proposals.

Before reporting a terminal-color problem, run `side-glance doctor --json` and include the Side Glance version, operating system, terminal, shell, tmux version if applicable, provider CLI and version, and sanitized diagnostics. Never include prompts, transcripts, access tokens, or unredacted provider configuration.

Security concerns belong in the private process described by [SECURITY.md](./SECURITY.md).
