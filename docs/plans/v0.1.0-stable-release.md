# Plan: Side Glance v0.1.0 stable release

> Derived from: `docs/specs/v0.1.0-stable-release.md`
> Status: in progress
> Last updated: 2026-08-29

## Overview

Turn the stable-release contract red before changing production metadata, then
align the package, CLI, current public surfaces, and release documentation. Run
focused and complete gates, record a five-axis review, merge through protected
`staging` and `main`, publish from one annotated protected tag, and independently
verify every public channel before updating Homebrew.

## Architecture decisions

- **Keep Side Glance's release workflow.** Ultracite's explicit version PR is a
  useful human gate, but its npm-only Changesets pipeline does not replace Side
  Glance's native archive, checksum, attestation, or Homebrew requirements.
- **Make stability a synchronized contract.** Version metadata, install paths,
  current product copy, and validation tests change in one release-preparation
  branch.
- **Preserve evidence qualifiers.** Package stability does not alter individual
  provider or platform support levels.
- **Keep history immutable.** Beta releases and their dist-tag remain intact;
  stable publication moves only `latest`.
- **Publish only from protected main.** The tag is the release input, not the
  feature branch or a locally assembled one-off bundle.

## Checkpoints

- [ ] The RED failure proves the test observes current beta state.
- [ ] Stable copy never erases provider/platform maturity qualifiers.
- [ ] Exact release-preparation tree passes every local gate.
- [ ] Exact protected merge SHAs pass their required remote checks.
- [ ] Public npm, GitHub, native, and Homebrew bytes agree on `0.1.0`.

## Rollback

- Before tag: revert or repair through protected PRs.
- After tag but before publication: retain the tag as an audit record, fix the
  workflow through protected branches, bump, and tag the next version.
- After npm publication: never replace bytes; deprecate if warranted and fix
  forward with `0.1.1`.
- If Homebrew alone fails: repair the tap PR without mutating the release.
